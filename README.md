# Distributed Decoupled Price Tracker

An enterprise-grade distributed system designed to monitor product price drops across e-commerce vendors using a decoupled Cloud API and a local residential scraping worker.

## Tech Stack
* **Backend API:** Java 17+ / Spring Boot
* **Database:** PostgreSQL with Flyway Migrations
* **Worker:** Python 3.11+ / Playwright
* **DevOps:** Docker, GitHub Actions, Google Cloud Run
